# Python String Programs

A collection of commonly asked Python string programs for interview preparation and logic building.

Each folder contains:
- Python source code
- README file explaining the logic
- Example input/output
- Time and space complexity

8. Remove Duplicate Characters

12. First Repeating Character

--------------------------------------------------
HOW TO RUN A PROGRAM
--------------------------------------------------

Open terminal inside any program folder and run:

python filename.py

Example:

python reverse_string.py

--------------------------------------------------
LEARNING GOAL
--------------------------------------------------

The goal of this repository is not just to memorize solutions
but to understand the reasoning and logic behind common string
manipulation problems frequently asked in technical interviews.
