# Reverse String
 
## Problem
 
Reverse the given string.
 
### Example
 
Input:
hello
 
Output:
olleh
 
## Logic
 
Python slicing syntax:
 
```python
string[start:end:step]
```
 
Using:
 
```python
text[::-1]
```
 
means:
 
- Start from end
- Move backward
- Take every character
 
Thus:
 
hello
 
becomes
 
olleh
 
## Time Complexity
 
O(n)
 
## Space Complexity
 
O(n)
